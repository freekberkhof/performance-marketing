# Performance Plus — drie werkende websiteconcepten

Afzonderlijke statische ontwerpomgeving op branch `design/performanceplus-mobbin-options`. Start `index.html` via een statische webserver; geen installatie nodig. De Next.js-productiesite is ongewijzigd.

- `light.html`: licht, fotografisch, interactieve functietabs.
- `warm.html`: crème/salie, redactionele opbouw, cliënt/praktijkwissel en stappenrondleiding.
- `dark.html`: grafiet en gedempt staalblauw, groot sportbeeld en appschermwissel.
- Alle varianten: mobiel menu, conceptwisselaar, FAQ, app-rondleiding en contactvenster dat uitsluitend een e-mailconcept maakt. Geen backend of automatisch versturen.

## Bronnen
Originele witte P+-logo en app-02/03/04 komen uit bestaande Performance Plus-beelden. Appschermen tonen testdata en zijn geen live app. strength/daylight/basketball zijn tijdelijke gegenereerde sfeerbeelden, geen echte cliënten of medewerkers.

Ontwerpinspiratie: Bevel via Mobbin (fotografische productcomposities en functieselectie), Oura (warme rustige kleuren), The Performance Lab (sportieve redactionele compositie). Geen Mobbin-screenshots in het eindproduct.
